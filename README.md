# Руслан & Гульзифа — Свадебное приглашение

Онлайн-приглашение на свадьбу. React + Vite + Tailwind CSS.

**Дата:** 31 июля 2026  
**Место:** с. Аскарово, Парк «Урал-батыр»

## Запуск локально

```bash
npm install
npm run dev
```

## Деплой

Проект деплоится на [Vercel](https://vercel.com). Достаточно подключить репозиторий — сборка настроена автоматически.
